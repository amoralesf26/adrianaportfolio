# CV web de Adriana Francia Higinio

Landing page bilingüe y adaptable a móviles, construida con Vinext/React. Incluye el CV completo, cambio dinámico entre español e inglés y descarga del documento original.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub y sube el contenido de esta carpeta.
2. En **Settings → Pages**, selecciona **GitHub Actions** como fuente.
3. Cada cambio enviado a la rama `main` se publicará automáticamente con el workflow incluido.

El sitio calcula automáticamente la ruta base cuando se publica como página de proyecto.
